# Study Time Tracker

A Python command-line tool for tracking study sessions and viewing study-time summaries.

## The Problem

It can be difficult for students to keep track of how much time they spend studying different subjects and understand where most of their time is going. When this information is scattered across notes or not recorded at all, it becomes harder to recognize study patterns and manage time effectively.

## How It Works

The MVP will allow a user to:

- Record a study session with a subject, duration, and date.
- Save study sessions to a CSV file.
- Read saved study data.
- Display total study time by subject.

## MVP Scope

The first version will focus on reliably recording study sessions, storing the data in a CSV file, and displaying study-time totals by subject.

## Tech Stack

- **Language:** Python
- **Libraries:** Python standard library, mainly `csv` and `datetime`
- **Data Storage:** CSV file
- **Version Control:** Git and GitHub
